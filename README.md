# Labs · Piras na Física

Site de **https://labs.pirasnafisica.com.br**: simuladores e ferramentas de Física (conversor de unidades, força elétrica, gráficos científicos, pêndulo forçado, simulador de movimento, jogo da alfândega e juntar PDFs).

Site estático (HTML, CSS e JS puros, sem build), publicado pelo GitHub Pages a partir da raiz deste repositório. Contém **somente os arquivos publicados**.

Para ver localmente:

```bash
python -m http.server 8000
# http://localhost:8000
```
